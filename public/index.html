Computed live by the real limiters running in memory on a simulated clock, so this costs no Redis and no waiting. These are not the published figures: those were measured against a real Redis server over real time, with a network in the way, and are in loadtest/README.md.

Now the hard part

Everything above is one process stepping a clock by hand. This is fifty genuinely concurrent requests against a shared Redis, run twice: once against a limiter that reads, decides, then writes, and once against one that does all three inside a single Lua script. Both are limited to five.
